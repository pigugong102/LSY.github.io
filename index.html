🛠 개발 — 문제 해결 과정 (Troubleshooting)

이슈 1
(AI 필터링 토큰 소진 예외 처리)
🚨 문제 상황

게시판 AI 욕설 필터링 기능 동작 중 OpenAI API 토큰(크레딧)이 전부 소모되었을 때, API 호출 에러(429 Too Many Requests)로 인해 게시글 및 댓글 자체가 등록되지 않는 문제 발생

💡 해결 방안

게시글·댓글을 선 저장 후 @Async 비동기로 AI 필터링을 시도하되, 토큰 소진 등 API 문제로 검수가 실패할 경우 예외 처리(Fallback)를 통해 글이 정상 등록되도록 개선하여 서비스 중단 방지
